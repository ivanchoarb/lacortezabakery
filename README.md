# La Corteza Bakery & Coffee

Sitio web de La Corteza Bakery & Coffee — panadería artesanal y café en
Granada, Cali. HTML/CSS/JS estático, sin dependencias.

## Ver en local

```
python3 -m http.server 8000
```

Abre `http://localhost:8000`.

## Deploy

Cualquier hosting estático sirve (GitHub Pages, Netlify, Vercel). No hay
build step.
